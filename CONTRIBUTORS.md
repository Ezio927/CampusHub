# Contributors

CampusHub was built by a four-person course team. Personal names are omitted; the original commit email addresses are retained in the Git history.

The project documents describe these role areas:

| Contributor | Project area |
| --- | --- |
| Member A | Backend foundations, user accounts, and authentication |
| Member B | Backend demands, orders, and related business flows |
| Member C | Frontend pages, interactions, and integration |
| Member D | Testing, quality, and notification integration |

These role labels summarize the team plan in `docs/P4/交付物1-spring合并任务看板/交付物1-spring合并任务看板.md`; they are not a complete attribution of every individual change.
